# Spreadsheet template

`exam-questions-template.csv` is for contributors who have many questions. Open it in Excel, Google Sheets or LibreOffice, and put one numbered question on each row. Keep all parts of a question, (a), (b), (c), in the same cell, in the order they appear on the paper.

| Column | What to write |
|---|---|
| exam | For example GCE Ordinary Level. |
| subject | As printed on the paper. |
| year | Four digits. Leave empty if unknown. |
| paper | For example Paper 2. |
| section | For example Section I. |
| question_number | As printed. |
| question_text | The whole question with all its parts and marks. |
| marks | Total marks for the question. |
| figure_description | A description in words of any diagram, graph or table. |
| answer | Only if you are sure it is correct. |
| answer_explanation | A short worked explanation if you have one. |
| topics | Topic names separated by semicolons, for example algebra;linear equations. |
| language | en or fr. |
| source | One of: past paper, written by me, textbook, other. |
| rights | One of: my own work, permission granted, official past paper, not sure. |
| contributor | The name you want for credit. |

When you save, choose CSV with UTF-8 so that accents are kept. Then send the file through the "Send a spreadsheet of questions" form in the Issues tab.
