# Dataset Catalogue

A catalogue of Cameroonian datasets that live elsewhere. We record each one with its steward, licence and link instead of copying it.

This folder is organised into the subfolders below. Each subfolder has its own guide explaining what belongs in it.

- `languages-and-speech`: Speech and language datasets held by other organisations, including Pidgin and national languages.
- `geography-and-maps`: Map and boundary datasets held by other organisations.
- `education-and-exams`: Education and examination datasets held by other organisations.
- `other-datasets`: Any other Cameroonian dataset held by another organisation.
