# Languages

The languages Cameroonians speak, write and mix.

This folder is organised into the subfolders below. Each subfolder has its own guide explaining what belongs in it.

- `english`: Cameroon English usage, vocabulary and writing.
- `french`: Cameroon French usage, vocabulary and writing.
- `cameroon-pidgin-english`: Cameroon Pidgin English text, speech and translations.
- `camfranglais`: Camfranglais text, speech and translations.
- `national-languages`: Text, speech and word lists in Cameroon's national languages. Use one subfolder per language, named by its ISO 639-3 code.
- `parallel-corpora`: Aligned translations between any pair of languages spoken in Cameroon.
- `speech-recordings`: Recorded speech with careful transcripts and speaker consent.
- `dictionaries-and-glossaries`: Word lists, dictionary entries and specialist glossaries.
